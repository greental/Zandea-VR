# Remaining downloaded props

This set adds the 32 distinct models still unused from `C:/Users/green/Downloads/Props` after the first nine Slice 8 imports. The original archives remain in Downloads. Exact duplicate archive copies are represented once.

`Tools/Props/extract_remaining.py` extracts nested archives to `Tools/Props/work/remaining-import/`. `Tools/Props/import_remaining.py` uses Blender 4.5 or later (`ZANDEA_BLENDER` can point to its executable) to remove loose vertices, reduce dense meshes, normalize approximate scale, export FBX models, and save each material's albedo as a separate PNG. Run `Tools/Props/correct_remaining_albedos.py` afterward for four FBX sources whose embedded image links are missing or wrong. These exports are generated assets, not new art. `Tools/Props/render_remaining_contact.py` can make a geometry contact sheet without opening Unity.

In Unity, **Zandea > Props > Build Remaining Downloaded Prefabs** creates `Zandea_*.prefab` assets in `Assets/MyAssets/prefabs/buildings/props/`, URP materials, colliders, and grab components for suitable physical items. Four source packs also yield 25 individual placeable parts (blacksmith tools, two assembled barrels, seven market pots, and five roadblock sections). `RemainingPropCatalog.asset` holds all 57 prefab references by ID and category, and `ZandeaOutpostProps.asset` links to the catalog for POI authoring. This tool does not replace the existing nine prop prefabs or edit an authored settlement. It may be rerun to refresh this set.

The physical vessels are grabbable. `Tools/Props/fracture_remaining_vessels.py` creates offline, mesh-derived shard FBXs for 19 vessel prefabs (including four Pueblo jars and pots). **Zandea > Props > Build All Vessel Breakage** creates debris prefabs and connects the existing `BreakableProp` combat and collision behavior. Brass vessels have higher impact and damage thresholds than ceramic. The seven-pot source group becomes seven independent breakables. Directly authored Pueblo pot instances keep their existing physical setup; the runtime also upgrades their scene mesh copies through a mesh-reference catalog, so Main's authored layout can be damaged without rewriting the user's scene. Run the breakage builder after the ordinary remaining-prop builder if rebuilding manually; the ordinary builder also reruns it when all 19 fracture FBXs are present.

Campfires are scenery only; they do not emit light or cause damage. The ladder is scenery and does not add climbing. Scanned statues are static scenery. Review each downloaded model's license and attribution before distributing it.
