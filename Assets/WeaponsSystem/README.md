# Weapons System Runtime

Initial migration of the weapons system from staging into `Assets/WeaponsSystem`.

## Quick auto-setup (ship)

1. Select your **ship root** in the Hierarchy.
2. Either:
   - **Component → VR Koombar → Combat → Ship Weapons Setup Trigger**, then in the Inspector click **Add / Refresh Weapons System on This Ship**, or
   - Menu: **GameObject → VR Koombar → Add Weapons System to Ship**.

This creates `Assets/WeaponsSystem/Data/AutoGenerated/` assets if needed, adds shields/damage/subsystems/modes, two hardpoints under `Weapons/` (laser primary, kinetic secondary), `WeaponGroupController`, and `DefensiveDisengageController`. **Assign projectile prefabs** on `WeaponDefinition_Laser_Default` and `WeaponDefinition_Kinetic_Default` before play. Call `WeaponHardpoint.TrySetDeployed(true)` before firing.

### Ship Weapons Orchestrator (recommended)

Add **Component → VR Koombar → Combat → Ship Weapons Orchestrator** on the ship root (the default setup menu adds it and wires `WeaponGroupController`, hardpoints, `SitInCockpit`, and `HOTASJoystick` if present).

- **Cockpit fire:** Assign **Fire Trigger Action** to your XR trigger (e.g. *Right Hand → XR Controller → trigger* or your project’s Input Action asset). While **Joystick Trigger Fire** is on, you fire the **selected weapon group** only when **seated** (`SitInCockpit`) and **grabbing the stick** (`HOTASJoystick`), and the trigger is pressed past the threshold.
- **Weapon group:** Use the **Selected Group** enum (Primary / Secondary / Utility), or call **`SelectPrimary` / `SelectSecondary` / `SelectUtility`** from UI **Button** OnClick.
- **Inspector (Play Mode):** Per-hardpoint deploy toggles, **Deploy all / Stow all**, **Test fire**, and quick group buttons (custom editor).

### Firing in play mode (mouse test only)

Add **Ship Weapons Play Mode Test Input** for **hold Left Mouse** = primary, **Right Mouse** = secondary without XR. Disable or remove when using the orchestrator + trigger.
